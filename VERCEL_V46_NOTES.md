# Faeyza Store V46 — Brand Rename + Admin Password

V46 renames the public site brand from the previous brand name to Faeyza Store across source, generated pages, PWA metadata, admin UI, SEO metadata, and project/package branding.

It retains the V45 admin password login and the V44 Hobby-compatible 11-function deployment guard.

Before production use:
- Set ADMIN_PASSWORD in Vercel Environment Variables.
- Set SITE_URL to the real production domain.
- Configure GitHub/analytics/affiliate environment variables as needed.
- Replace demo placeholder affiliate URLs with real affiliate links.

# Faeyza Store V19

V19 menambahkan discovery katalog tanpa backend tambahan:
- pencarian produk;
- filter kategori;
- filter rating minimum;
- filter harga maksimum;
- halaman hub `/perbandingan/`;
- pencarian daftar perbandingan;
- perbandingan menyajikan data tanpa memilih pemenang otomatis.

Semua filter berjalan client-side pada halaman statis. Tidak ada API key baru.
